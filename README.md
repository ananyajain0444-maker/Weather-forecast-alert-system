# 🌦️ Weather Forecast & Alert System

A Python-based intelligent weather analysis system that fetches real-time weather data using APIs, processes forecasts, generates automated alerts, and visualizes weather
trends using charts.

---

# 🚀 Project Overview

This project is a real-world Python application that:
- Fetches live weather data using Open-Meteo API
- Analyzes temperature, humidity, and rain probability
- Generates automated weather alerts
- Produces 4 professional visual charts
- Saves structured data into CSV files

It is designed for **Data Analyst, Python Developer, and API Integration portfolio projects**.

---

# 🎯 Features

- 🌍 Real-time weather data fetching (Open-Meteo API)
- 🔥 Heatwave detection system
- 🌧️ Rain probability alerts
- 💧 Humidity monitoring
- 📊 Automated data visualization (4 charts generated)
- 📁 CSV report generation
- ⚙️ Modular and scalable Python architecture

---

# 🧠 Tech Stack

- Python 3.10+
- Requests (API calls)
- Pandas (data processing)
- Matplotlib (visualization)
- Open-Meteo API (free weather API)

## ⚠️ Alert System Logic

The system automatically generates alerts based on weather conditions:

- 🔥 Temperature > 35°C → Heat Alert  
- 🌧️ Rain probability > 60% → Rain Alert  
- 💧 High humidity → Humidity Alert
